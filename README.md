## Cómo empezar (Google Colab)
1. Abre https://colab.research.google.com → *Archivo → Subir cuaderno* → elige el laboratorio.

3. Cuando el cuaderno lo pida, sube el archivo de datos desde la carpeta `datos/` (ícono de carpeta 📁 a la izquierda, o el diálogo que aparece automáticamente).
4. Ejecuta las celdas **en orden** con `Shift + Enter`.
